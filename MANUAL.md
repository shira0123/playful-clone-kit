# Setup and Management Manual
## EVOLVE TRADE HUB Platform

### Overview
This repository contains a full-stack web application built using modern TypeScript tools:
- **Frontend/Framework**: [TanStack Start](https://tanstack.com/start) with React, TanStack Router, and Tailwind CSS.
- **Backend**: TanStack Server Functions (API layer).
- **Database ORM**: [Drizzle ORM](https://orm.drizzle.team/) running on PostgreSQL (e.g. Supabase).
- **Authentication/Emails**: Custom session-based auth and emails sent via Resend.

---

### Folder Structure
- `src/routes/`: Contains all frontend pages and layouts. Note that TanStack Router uses a file-based routing system (`.tsx` files).
  - `/admin.*.tsx`: Admin dashboard pages.
  - `/dashboard.*.tsx`: User dashboard pages.
- `src/server/db/`: Database configuration, Drizzle schemas (`schema.ts`), and seed scripts (`seed.ts`).
- `src/server/services/`: Backend logic, database queries, and third-party integrations (Admin, Auth, Investments).
- `src/server-fns.ts`: TanStack Server Functions which act as the bridge between frontend and backend.
- `src/components/`: Reusable React components (UI elements like buttons, cards, inputs).
- `drizzle/`: Database migration files generated by Drizzle Kit.
- `scratch/`: Temporary scratchpad scripts (e.g., `test-email.ts`).

### Initial Setup (New Machine or Server)
Follow these steps to set up the project on a new local machine or production server.

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd playful-clone-kit
   ```

2. **Install Dependencies:**
   Make sure you have Node.js installed (v18+).
   ```bash
   npm install
   ```

3. **Environment Variables:**
   Copy the example environment file and fill in your credentials.
   ```bash
   cp .env.example .env
   ```
   **Required Variables:**
   - `DATABASE_URL`: PostgreSQL connection string (e.g., from Supabase).
   - `RESEND_API_KEY`: API key from [Resend](https://resend.com) for sending emails (auth, verification). *Note: Ensure your domain is verified on Resend, otherwise emails to standard addresses will fail with a 422 error.*

4. **Database Setup & Migrations:**
   Push the schema to your connected database.
   ```bash
   npx drizzle-kit push
   ```
   *Seed initial investment plans and crypto wallets:*
   ```bash
   npx tsx src/server/db/seed.ts
   ```

5. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Access the app at `http://localhost:8081` (port might vary if in use).

### Essential Commands
- **Start Development Server:** `npm run dev`
- **Build for Production:** `npm run build`
- **Start Production Server:** `npm run start` (Run after build)
- **Database Push:** `npx drizzle-kit push` (Applies schema changes directly to DB)
- **Database Generate:** `npx drizzle-kit generate` (Generates SQL migration files for version control)
- **Database Studio:** `npx drizzle-kit studio` (Opens a local visual database editor in your browser)

### Admin Management Guide
By default, the first user to register doesn't have admin rights. To promote an account to Admin:

1. Register an account normally via the web interface.
2. Run the make-admin script in your terminal:
   ```bash
   npx tsx src/server/scripts/make-admin.ts <your-email@example.com>
   ```
3. Log in (or refresh the page). You will now see the Admin Dashboard.

**Admin Capabilities:**
- **Manage Users:** Suspend accounts, forcibly verify emails, and reset passwords.
- **Impersonate User:** Login as any user instantly to troubleshoot issues. *(Note: Impersonating immediately logs you out of your Admin session and redirects you to the user dashboard. To regain admin access, sign out of the user's account and log back in).*
- **Manage Investments:** Review, Approve, Reject, or Cancel active investment plans. Admins are automatically hidden from this list to prevent clutter.

### Super Admin Role
To strictly enforce administrative powers (such as creating or deleting other admins) and managing global funds, the platform supports a single `super_admin` role. 
1. Register an account normally.
2. Run the super admin script:
   ```bash
   npx tsx src/server/scripts/make-super-admin.ts <your-email@example.com>
   ```
*Note: Running this script automatically demotes any existing Super Admin back to a regular Admin, ensuring only one Super Admin exists at any given time.*

### Modifying Crypto Wallets & Plans
Currently, crypto wallets and investment plans are seeded via the database script. 
If you need to update wallet addresses or add new plans:
1. Open `src/server/db/seed.ts`.
2. Update the `cryptoWallets` array or `investmentPlans` array.
3. Run `npx tsx src/server/db/seed.ts`.

---

### Daily ROI Processing
To automatically distribute daily profits to users based on their active investment plans, run the provided script on a schedule (e.g. daily at midnight via CRON or PM2).

```bash
npx tsx src/server/scripts/process-daily-roi.ts
```
This script will loop through all `active` investments, calculate the daily returns from the plan's `roiPercentage`, update the user's `profits` balance, and update the investment's `currentProfit` tracking field.
